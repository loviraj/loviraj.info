# Dr. Lovi Raj Gupta — Portfolio

Static multi-page portfolio for **loviraj.info**, designed around academic leadership, research, books, patents, innovation and public-facing learning content.

## Pages
- `index.html` — visual home, portrait, innovation brands, patent authority panel, video highlights and books
- `about.html` — academic profile, education, memberships and continuing learning
- `books.html` — eight books with publisher / book-detail links
- `research.html` — research territories, selected publications and identifiers
- `patents.html` — patent and software-IP portfolio
- `innovations.html` — TeachGenie, Engageneering, Assess-A-Thon and MARS
- `videos.html` — speaking, learning-video and upcoming YouTube-series showcase
- `journey.html` — career timeline and selected milestones
- `contact.html` — contact form and direct contact details
- `404.html` — fallback page
